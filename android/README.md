# S Device Android foundation
Native Kotlin Android starter application, not yet a home replacement/ROM.
Open the android/ directory in Android Studio. Install Android SDK platform 35 and compatible Android Gradle plugin. Build with Gradle (Android Studio can generate wrapper files; wrapper not checked in).
Initial screen is static on purpose. No runtime permissions, network requests, personal data collection or credentials.
Future milestones: custom HOME role (opt-in), design system, authenticated HTTPS API client, AI adapter with explicit permissions, launcher usability and Realme physical testing.
Building and running on the user's phone is NOT verified.
