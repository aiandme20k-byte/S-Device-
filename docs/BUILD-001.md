# BUILD 001: Phone assessment and safe rebuild

Status: PLANNED — physical tests have NOT been conducted.

## Observed from reference photos
- Samsung branded blue rear housing, visibly cracked.
- Rear camera assembly visible; exact model not established.
- Front display dark. This alone does not prove screen, motherboard, or battery failure.

## At home: without opening the device
1. Photograph every exterior side and charging port (avoid disclosing serial/IMEI).
2. Look for swelling, lifted seams, heat, leaks or unusual smell. If present STOP; avoid charging or pressing on the phone; seek a professional.
3. If safe, try the original compatible charger and known-good cable.
4. Note whether the phone vibrates, rings, starts, or shows any image; do not force a damaged display.
5. If screen operates, back up essential data to a trusted local machine before any repair.
6. Record the exact model identifier via Settings > About phone if accessible, or have the repair shop identify it.

## Repair shop request
- Identify precise model/SM-xxxx variant, display type, touch and frame compatibility.
- Check battery swelling and health; professionally replace if unsafe or deteriorated.
- Test charging port, cameras, microphones, speakers, Wi-Fi, SIM, fingerprint and power buttons.
- Quote separate costs: screen module, adhesive, rear panel, labor; confirm data preservation.
- Require power-on and touch tests after installation before final sealing.
- Avoid removing Google/Samsung security features or bypassing account locks.

## Verification gate
Record PASS/FAIL/UNKNOWN for boot, screen, touch, charge, battery, connectivity, cameras, microphone, speaker, temperature and enclosure integrity.
Only proceed to firmware/software customizations after core safety and functionality pass.

## Vision upgrade plan
- Android launcher first; reversible and low-cost.
- Accessible voice assistant with transparent network/local mode indicators.
- Optional 5 V USB-powered ESP32 demo, physically isolated from phone battery.
- Pepper's Ghost prism or miniature reflective optical display: clearly labeled optical illusion.
- Custom casing only after thermal, antenna and fit assessments.
