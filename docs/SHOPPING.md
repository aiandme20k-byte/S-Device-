# Shopping guide — do not order replacement screen until model confirmed

## Priority 1
- Exact-model replacement screen assembly (professional fit)
- Exact-model rear glass/back panel and adhesive
- Qualified battery diagnostic/replacement if needed
- Protective case and screen protector

## Priority 2 — optional DIY
- USB-C/OTG adapter matched to phone port
- External USB-powered ESP32-S3 dev board (optional)
- Small compatible SPI TFT/OLED display module
- USB 5 V power bank, fused or protected power cable
- Clear acrylic optical prism, cut safely or bought premade
- USB webcam/phone stand and diffuser for AR-style visuals

## Budget rules
Request repair estimates first; compare total repair cost to a working used device.
Match screen/frame/flex connector and regional model EXACTLY.
Check seller photos/reviews, return policy, total shipping and supported voltage.
Never connect a generic ESP32 board directly to battery terminals or phone's internal screen connector.
