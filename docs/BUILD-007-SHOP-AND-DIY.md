# S Device: Do first, buy last
1. DO NOW: preserve Realme stock hardware; backup photos/files, verify Windows/PC Python and server tests, start S Device UI on PC.
2. DO NOW: check spare HDMI monitor/TV and PC video output; simulate projector web dashboard without buying hardware.
3. BORROW: projector or USB display to test brightness, focus and inputs.
4. BUY ONLY AFTER TESTS: suitable native-input projector, compatible cable/stand, optional optical-prism module, all protected USB powered.
5. DO NOT BUY: laser/nebula room-light projector as a substitute for a video projector, low-quality projector marketed as 4K without native spec, bare Li-ion cells, cross-model phone display flex, mains electronics salvage for beginner testing.
6. DO NOT DO: fuse AC power input or unknown chargers into custom boards; replace phone power management with purported ZPE device; claim lifetime charge.
7. Repair shop assignment: custom detachable enclosure/dock only. Ask about mechanical fit, heat, antenna obstruction, USB access and reversible installation.
8. GitHub logs should omit faces, private camera feed, precise location, IMEI, phone numbers, passwords and raw voice audio.
